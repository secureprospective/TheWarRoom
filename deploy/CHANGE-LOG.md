# Hot patch and upgrade log

Every Lab hot patch, every Season server install, upgrade or rollback, and every release hold gets
one entry here (CLAUDE.md, Environments, rules 7 and 8). Routine automatic Lab releases are recorded
in their own release folders and are not repeated here. Newest entry first. Times are Central.

The point is to learn the hot-patch and upgrade cadence on the Lab before it is used anywhere else.
So record what went wrong and what to change, not only what was done.

## Entry template

### YYYY-MM-DD HH:MM · lab | season · hot patch | install | upgrade | rollback | hold

- **From → to:** version and commit, or "none" for a first install
- **Why:**
- **Approved by:** Christopher (exact message or tracker card), or "Lab, no OK needed"
- **Commands:** the exact lines that were run
- **Took:** start to healthy, in minutes
- **Checks after:** health, leagues load, live screen, backups
- **What broke:** or "nothing"
- **Rollback needed:** no, or yes plus what was restored
- **Next time:** what to change in the process
