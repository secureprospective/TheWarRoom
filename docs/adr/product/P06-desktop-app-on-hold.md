# The standalone desktop app and old local mode are on hold

Status: Accepted by Christopher
Date: 2026-11-22

**Decision.** The standalone desktop app and the old local mode are under review in the reset. Nothing new is built on them until Christopher rules. The desktop browser version (mock v3) stays fully supported.

**Why.** They are the biggest leftover of the old direction; this stops work piling onto them before the decision.

**What it means for agents.** New features go to the hosted server and the web app only.
