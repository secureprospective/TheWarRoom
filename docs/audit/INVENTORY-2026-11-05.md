## 2. End-to-end data flows

### MFL import and sync
```text
MFL API → shared Client (2 requests/s, burst 1, discovered host)
  → archive.Transport → history raw_archive + fetch_log
  → Raw feed Parse / Validate → normalized rules / roster / salary adjustments
  → staged rulebook + league_mirror → CommitPrepared (same main-file transaction)
  → mirror Reader → snapshot / UI; model marked dirty
Separate migration: held MFL evidence → native seed/import → history league_event
Feed failure → newest valid archive matching export + season + league (+ week)
  → HeldFeed with stale provenance → UI; no usable body → fail, not invented data
```
Edges: `internal/composition/app.go:146`; `internal/composition/refresh_app.go:72`; `internal/app/report/held.go:132`; `internal/composition/migration_app.go:27`; `internal/archive/archive.go:63`.

### Native league authority
```text
UI / CLI / hosted HTTPS → command registry → leagueservice
  → RawCommand validation + admission + principal / expected revision / confirmation
  → history immediate transaction → append-only league_event + audit chain / receipt
  → commissioner folds (rules / roster / market / lineup / schedule / results)
  → filtered authorized reading → transport response → TS parser → screen
DueWorker → same service admission / append path → native clocks / scheduled work
MFL capture is an import into this same native settings/ledger path, not remote MFL writes
```
Edges: `internal/commandcatalog/registry_handlers.go:41`; `internal/store/history/commissioner.go:155`; `internal/leagueservice/due_worker.go:45`; `internal/serverhttp/hosted.go:35`.

### Stats provider ladder (per statistic, not a whole-feed switch)
```text
ESPN scoreboard / box scores (busy 1 min, idle 5 min, finals reread 10 min)
  → validated live lines matched through player_ids
Sleeper → fills missing player/stat fields or handles ESPN failure
  → history live revisions persisted + in-memory live lines → moves signal
Held nflverse weekly + plays + snaps + injuries + depth / absence evidence
  → heldSeason decoding/index → authoritative final NFLVerse fields
MergeStatSources priority: nflverse > ESPN live > Sleeper; MFL not a score fallback
  → native player/week scoring under league rules → results / standings / odds / stat queue
```
Edges: `internal/app/now/live_stats.go:23`; `internal/app/now/live_sleeper.go:24`; `internal/fantasyscore/source/precedence.go:24`; `internal/store/history/live_storage.go:12`; `internal/store/history/held_season_cache.go:159`.

### Engine and valuation
```text
Background refresh → load signals + season points + free agents → check dirty / input changes
  → modelrun with league mirror, params, held evidence + player records
  → pure engine / projection / valuation → durable model_runs + model_scores / manifests
  → published market model → season event
Independent prepared native values: one Preparation producer, league+season scope
  → revision + params + evidence + as-of window → Cache / prepared-values JSON
  → franchise scoped read (Preparing until current) → HQ / War Room / inspectors
```
Edges: `internal/composition/engine_refresh.go:18`; `internal/composition/engine_refresh.go:59`; `internal/appvalue/preparation.go:78`; `internal/appvalue/cache.go:44`; `internal/composition/asset_board.go:39`.

### Events and invalidation
```text
Desktop background feed / model / clock / plan change
  → target:season / target:clock / target:moves
  → subscribed provider / hook → at most running + queued reread → authorized read
Hosted history commit → server invalidation stream (no ledger payload)
  → desktop Go WatchInvalidations → authorized reread / replaced local view
  → WebView workflow onChange; reconnect starts with reread (no persisted cursor)
Session end → fence pending publications + reset registered stores / invalidate caches
```
Edges: `internal/composition/app.go:100`; `internal/composition/app.go:108`; `internal/serverhttp/invalidations.go:20`; `internal/serverclient/invalidations.go:28`; `frontend/src/app/data/session.ts:8`.

### UI reads
```text
Screen scope (league, franchise, filters, selection)
  → useContractRead OR createReadQuery (not interchangeable cache owners)
  → provider / workflow bridge → Wails API OR desktop HTTPS proxy → backend read
  → parse typed response → per-owner Zustand / hook publication → React view
Home starts independent tile sources; Pulse partial publication releases week-dependent sources
War Room first visit → retained hidden mount → hook state + subscriptions survive navigation
  → league / franchise key change or owner unmount disposes retained read state
```
Edges: `frontend/src/app/contracts/Contracts.tsx:28`; `frontend/src/app/data/query.ts:103`; `frontend/src/app/shell/homeReads.ts:52`; `frontend/src/app/shell/AppLeagueMount.tsx:49`; `frontend/src/app/shell/TargetApp.tsx:128`.

**Important distinctions:** archive fallback is on report feeds, not a blanket substitute for atomic settings/roster refresh; pending private trades require the current key generation and are cleared on key removal (`internal/composition/season_app.go:158–193`). The model-run pipeline and prepared native-value producer are distinct entry paths, not evidence that every screen runs the engine (`internal/composition/engine_refresh.go:74`, `internal/appvalue/preparation.go:66`).

## 4. Memory, caches and read lifetimes
**Terminology:** durable history is evidence, not disposable cache. Held feeds are last-good publications. Query flight maps deduplicate work but do not retain completed results. All byte sizes are unmeasured unless explicitly attributed to earlier profiling (`internal/app/report/held.go:18`, `internal/store/history/reading_flight.go:14`, `docs/debloat-log.md:9–25`).
