## Doubts

1. Only the cited origin/main files were opened; NEW is not a repository-wide absence claim. Backend implementations and permissions may exist elsewhere.
2. Owner versus commissioner, co-commissioner and DOT access is not specified in this mock.
3. Mock trades, plans, bids, notes and simulation are in-memory; labels suggesting autosave, execution or privacy are not evidence of persistence or authorization.
4. The partner selector does not update shelf, direction or send target; inspector contract, arc and lineup panels are static when a different asset is inspected.
5. Several later function declarations replace earlier renderers; the bid-segment title tooltip occurs only in a superseded renderer. Earlier confirmation handlers remain but their old buttons are not rendered by the final confirmation.
6. Market bid finality and hard cap semantics in the mock may conflict with real league rules; verify against the authoritative backend before implementing.
7. Plan checked state is indexed globally rather than per plan; links switch workspaces but do not select the named target, and some plan and queue buttons are inert or route to unrelated handlers.
8. Draft is a simulated mock, not evidence that a live draft or the stated ADP source is available. Scouting textareas, comparison and undo lack handlers; draft report backend support for personal notes remains unverified.
9. Negotiation acceptance displays processing without performing a transaction; only the first thread is wired and counter/decline handling is illustrative.
10. Refresh classifications express intended display behavior, not a verified subscription or stat feed; the mock has no true live stat feed.
