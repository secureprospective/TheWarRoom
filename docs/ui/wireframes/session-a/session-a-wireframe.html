Callouts — the design decisions

  • 1Portfolio sector, top of rail. League switcher lives at the top 160px; a pinned overview crest + recency micro-crests scale 1→25+ honestly. (Ruling 4.)
  • 2Phase-3 injection seam. The 1px divider at y=160px is exactly where a future cross-league portfolio module drops in — no rail redesign.
  • 332px module header. Title + view-toggle as heavy segmented buttons. Denser than a SaaS toolbar; every pixel earns its keep.
  • 436px sticky filter sub-header. Position chips pin on scroll (68px total fixed overhead). The board never loses its filter state.
  • 5Adjusted Score dominates. 14px bright tabular-nums, right-aligned — the "speedometer" read. Base/Salary recede to muted gray. Fixed zones, gradient fill.
  • 6Inspector = fixed 320px bay. Populates on any row click (no navigation); slides in/out via translateX overlay — it does NOT reflow the workspace width per click (honors the <100ms snappy law).
  • 7Comms right-edge strip. 48px idle, summons left as an overlay — costs zero table rows (this resolves Run 1's own ripcord).
  • 8Calendar seam. 32px top-right idle → generous 640×480 summon-over overlay. Both quick-dash panels are pure transforms, summonable from any screen.
