## HEAD-BRAIN RULINGS — implement these, do not relitigate

**R-A. The organizing model is BOTH runs composed — one timeline, verb-triaged.**
- The honest data model is Watch Floor's: every occurrence (feed event, chat message, calendar deadline, trade card, system alert) is ONE time-ordered event object. Keep that as the substrate.
- The default Feed is strict chronological (Watch Floor's river).
- LAYER ON the **Triage Tributary** (Watch Floor's own ripcord resolution): when an event escalates to `--signal-amber-loud` or `--signal-red-loud`, it is PULLED OUT of the chronological flow and pinned into an **ALERTS group at the top of the Feed**; `Esc` releases pinned alerts back into the river. This is what lets the 25-league operator teleport-to-the-fire instead of scrolling.
- LAYER ON **VAV (Verb Affordance Visibility)** from Ops Room as the casual↔operator scaler (NOT a mode toggle — an altitude): casual (1–2 leagues) = verb affordances always visible (short checklist); operator (many leagues) = affordances hidden, appearing on `:hover`/`:focus-within` OR when escalated. One grammar, two altitudes.

**R-B. Chat is a terminal-log thread, NOT bubbles.** Implement Watch Floor's full-width non-bubble thread: hairline (1px) row separators, timestamped rows, human chatter = Inter 13px `--text-primary`, typed command = Mono `> /verb` `--text-secondary`, system answer = Mono `↳ …` `--text-muted` with NO assistant persona (raw data response). DROP Ops Room's right/left-aligned bubbles entirely (bubbles are the SaaS tell we are avoiding). KEEP from Ops Room: the prompt `/`-pivot (on keystroke `/` the input's left axis gains `--edge-focus` blue + font switches to JetBrains Mono, cueing command mode without alienating the casual who just types text). KEEP from both: the in-thread **Control Card** (`/offer` spawns a full-width inset tile natively in the thread; Accept/Counter/Decline are inset-bevel micro-switches that route through the B ConfirmModal; card locks opacity 0.5 while the modal is active; on commit the card recedes to `[ COMMITTED — HH:MM ]`).

**R-C. Calendar: native drag-MOVE, but edge-resize is stepper-only (no native resize drag).** Both runs agree drag-move is compositor-safe (transform: translate ghost + 15-min snap, commit on RELEASE). SHIP that. For DURATION change: NO native edge-drag resize (the APU compositor risk is real, not a detect-and-fallback bet) — click the chip → inspector → tactical +/−15m duration stepper (`ui.event.resize`), commit fires `ui.event.commit`. Note in one line that a guarded native edge-resize is a v-next revisit IF the compositor floor improves. Everything else on the calendar the two runs converged on — implement it: Column-Share overlap (1px hairline divider; >3 overlaps → `+N more` aggregate chip opening a tactical dropdown); Month/Week/Agenda + a permanent Mini-Month navigator; event-chip = 2px left color bar in a SEMANTIC deadline hue (Waiver blue-base / Trade amber-base / Draft green-base / Roster-lock red-base — categorical POSITION badges do NOT apply on the calendar); click-empty→quick-create popover + click-drag-to-create ghost snapping 15-min.

**R-D. Append-only honesty (both converged — implement).** A dragged move does NOT mutate — it appends `EventSuperseded`; a 32px snackbar reads `Event moved. [UNDO]`; UNDO appends another revision (`EventUndone`), never deletes. History is preserved and honest.

**R-E. Adopt Ops Room's two good catches.**
- **Freshness rides the event spine:** a cached/offline event's Severity Spine shifts `--edge-freshness-live` (blue) → `-stale` (amber-muted), timestamp gets `(cache)` suffix. The C guardrail holds — freshness NEVER washes the data.
- **The `/history` verb** (resolves the recession-vs-audit tension): resolved/expired events recede to 50% opacity in the active Feed (calm, debt-free, no unread badges) AND remain in the calendar historical log; `/history` in the terminal dumps a clean 100%-opacity mono log of all resolved events. Active surface stays calm; the record stays exact.

**R-F. Escalation structural treatment — keep it cheap and non-decorative.** On escalation: Severity Spine widens 2px→4px (transform, cheap), spine + timestamp take the semantic hue (amber-loud <1hr / red-loud snipe-danger), row optically raises to `--surface-raised`, the event pins to the ALERTS tributary, and its verb affordance becomes persistent (VAV override). **CUT any pulsating/looping animation** — a persistent pulse is ambient decoration, which the C motion doctrine forbids (motion is feedback, not decoration). The widen + hue + raise + pin is enough signal. Recession = single 150ms opacity cross-fade, no loop.

**R-G. Cross-league = LEDGER-FLAGGED SEAM only, not built.** v1 renders the single-league surfaces cleanly. Expose the seam as a `[L: ALL] / [L: ACTIVE]` toggle at the Feed header (RETURN-SESSION flag for full aggregation), mirroring Session A's Phase-3 injection seam. Do NOT build multi-league grouping.

**R-H. Operational overlay (both converged — implement).** Deadlines project onto the surfaces they govern, not only the calendar overlay: a `Trade Deadline: Nd Nh` badge in the Trade Builder / ConfirmModal header (`--signal-amber-base`); a roster-lock countdown as a persistent workspace top-bar ticking `--signal-amber-loud` under 1 hour (the C clock<1hr rule).

**R-I. Data-model honesty (Watch Floor's ripcord alternative — adopt).** A chat message is an instantaneous point (no duration); it renders in Feed + Comms but is filtered OUT of the Month/Week calendar grid (calendar shows `is_scheduled==true` / `duration>0` events only). Do not force empty duration fields onto chat.
