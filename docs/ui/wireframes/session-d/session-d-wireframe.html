    Thread grammar

    Human chatter — Inter 13px, primary.  Typed command — Mono > /verb, secondary.  System answer — Mono ↳, tertiary, no assistant persona (raw data). One scannable, non-bubble thread — bubbles were rejected as the SaaS tell.

    The /-pivot prompt D
    ›Message or /command… (text mode · Inter)
    /offer warren for 2026-2nd (command mode · blue axis)
    Control surface in the conversation

    Accept / Counter / Decline are inset micro-switches inside the thread card; Accept routes to the Session B ConfirmModal (480px, hold-to-fire). While the modal is live the card locks to 50%; on commit it recedes to [ COMMITTED — 12:06 ]. Every switch has a Ledger verb.

    DTyping / flips the prompt to Mono + a blue focus axis — it cues the operator into command mode without alienating the casual, who just types text. The visual home is a command line; the engine that reads it is not designed here.
