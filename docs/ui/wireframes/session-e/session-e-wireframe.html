§3

The lessons ledger — the real deliverable (handed to a future mobile session cold)

R-G
◆ BINDS mobile — inherited, non-negotiable
Color & restraint doctrine
Color is Data + State; structure is achromatic. A notification list must NOT light up like a Christmas tree — hue is earned strictly via semantic escalation.
One-thread event grammar
Spine + timestamp + subject(600)/predicate(400) + verb-affordance is the universal translator — it scales perfectly to a single column. Everything is a message in the log.
Append-only truth
Events & actions are never mutated, only superseded (EventSuperseded/EventUndone). Temporal honesty maps 1:1 onto a chat thread.
Hold-to-fire actuation
The 480px modal dies; the gesture survives — ≤600ms fill, release-cancels, engine-reject holds. It prevents catastrophic fat-finger commits.
Token typography
Inter = text, JetBrains Mono = data/commands; hero numerics keep tabular-nums. The desktop hierarchy is preserved verbatim.
Optical elevation (no shadows/blur)
Hairlines + inset bevels + the surface ramp (sunken 4% → tile 9% → raised 11%) carry over — cheap-paint on mobile too. No dropshadows.
Command Ledger verbs (A1–D12)
Every action is still a verb — the mobile UI is a generator for txn.commit / feed.ack / cmd.execute. Slash-aliases (/rank, /trade) are user-facing skins the LLM resolves to these.
LLM input-normalization
Fuzzy voice/typo input MUST resolve to a canonical verb before any output (normalize-then-act). This is why the backbone is LLM-backed, not a rigid parser. (router preprocessing, not a mutation verb)
✎ MOBILE MAY BREAK — deliberate divergences
4-column instrument shell
A phone has room for ONE thing. → Single-column chat-first shell; nav/inspector/calendar splits die, dense boards relegate to chat-answerable cards.
Hover-dependent VAV
Capacitive touch has no hover to preview chrome. → Tap-to-expand slide-down drawer (primary); swipe reserved for ack/dismiss; escalation force-persists affordances inline.
480px centered ConfirmModal
A desktop measure that hijacks the viewport and feels heavy under a clock. → Inline hold-to-fire on the Control Card itself — commitment happens in situ.
Keyboard / J-K-T map
Phones lack a physical keyboard; a soft one is slow & intrusive. → Voice/mic input + the /-pivot & quick-verb accelerator rail; native touch scroll.
Density tiers (Matrix/Tactical)
22px rows need a mouse; 44pt touch targets override data-density cramming. → One comfortable touch density; the "Matrix" need is met by on-demand summary cards.
Dedicated boards (Home, M1, M4)
The operator can't visualize a portfolio at once on a phone. → Data exists when interrogated; the board becomes an answer to a question.

RIPCORD: none new. R-A (Inbox-onto-Oracle) resolves Run 1's proactive-interrogation gap; R-C (push deep-link) resolves Run 2's under-clock-typing gap. The two runs' RIPCORDs cancel each other in the composition.
