# Disposable hosted workflows

Development/test helpers only; release binaries never import this package.
`CreateWorkflowLeague` records rosters, free-agent pool, a short published schedule,
open action windows, blind bids and two-minute bid/waiver deadlines through canonical
commissioner commands. Its football evidence has future kickoffs and no invented final
statistics. `AddWorkflowOwner` uses real account enrollment and seat replacement APIs;
it grants no authentication override. The launcher provisions two ordinary owner seats
in addition to the commissioner so a nonparty commissioner can review a trade.

Launcher, cleanup rules and click walkthrough: `cmd/twr-practice/README.md`.
HTTPS and retry/privacy/replay evidence: `internal/serverhttp/market_workflow_test.go`.
