== CONSTRAINTS ACTIVE THIS SESSION ==
- Standards: <250-line target / 400 cap (make filelen); schema-validate at the
  boundary before anything downstream; no hardcoded host/IP (the client handles it);
  context.Context first arg; close is the client's job (fetcher just calls Do).
- Architectural: NO transformation in fetchers — validate the shape, return raw.
  String player IDs enforced at ingestion via playerid.New (RISK-003 call site #1).
  Filter team-aggregate IDs (range 0151–0782) HERE before they pollute downstream.
- Anti-spaghetti: a fetcher knows the SHAPE of one MFL response, nothing about
  scoring or domain semantics. One exported Fetch per file; fetchers don't import
  each other.
- Discovery ordering (Q2.1 deferral from B1): the INGESTION layer is responsible
  for calling c.DiscoverHost(ctx, year, leagueID) BEFORE any league-specific fetch.
  The transport intentionally falls back to the `api` host if discovery hasn't run
  (it does not hard-error) — so the correctness of "discover first" lives here, not
  in the client. Do not route around this; call DiscoverHost up front.
