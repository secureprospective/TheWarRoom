    "YFA" → UFA; anything else → flag for admin review. (Table in MFL_API_Reference.)
  * Position normalize: PK → K; filter PN/Coach/TM*/Def/ST/Off; XX → FLAG;
    EDGE → per OQ-004. NGS anchor is CB/S only (downstream, not here).
  * Player IDs string ALWAYS via playerid.New (RISK-003 site #2). All SQLite TEXT.
- Anti-spaghetti: normalize transforms; it does not fetch and it does not score.
  domain types import nothing internal (leaf). Stores/engine come later.

== CARRIED FROM LAST SESSION (B2 learnings) ==
- Decisions made (locked, B2):
  * Fetch signatures take year (and leagueID where league-specific) as ARGUMENTS,
    not package globals (#4A) — data-driven, testable, multi-league/season-ready.
    ingestion.SeasonYear / ingestion.LeagueID are the canonical Phase-1 values a
    caller passes. Keep this convention for the players fetcher.
  * Fail-loud per-record on malformed data (#3) — one bad record errors the batch
    (rosters data is clean; surfaces schema drift). Revisit partial-success
    (errors.Join) ONLY if a genuinely dirty fetcher needs it. B3 normalization is a
    transformation, not a batch fetch — decide its own error policy deliberately.
  * RawRoster carries the FULL rosters shape as raw strings incl. salary (Christopher
    chose full-shape) — so normalize is the single place salary string→float happens.
- Mistakes / learnings (apply these):
  * MFL collapses a single-element array to a bare OBJECT (XML→JSON legacy). The
    rosters fetcher's array decode would have CRASHED on a 1-player franchise — fixed
    with the reusable ingestion.MFLList[T] decoder (sniffs '['). USE MFLList[T] for
    EVERY MFL list field in the players fetcher (players.player[] especially). Gemini
    first-instance review caught this as a BLOCKER; linters could not see it.
  * Empty payload {"rosters":{}} decoded to a silent empty slice (DB-wipe risk
    downstream). Both fetchers now guard zero-length with a sentinel error. Add the
    same guard to the players fetcher (an empty players DB is a glitch, not valid).
