Research date: 2026-10-03. Complete with explicitly unresolved verification gates.

## Confirmed breaking change
The old `player_stats` release says **“DEPRECATED 2025-08-01: USE `stats_player` OR `stats_team` INSTEAD”**. Both generated 2026 URLs in the code return HTTP 404. Release metadata independently contains neither 2025 nor 2026 old-style season files. This is a stale URL/schema, not a dead nflverse project.

- https://nflreadr.nflverse.com/reference/load_player_stats.html (readable documentation retrieved): `stat_type` deprecated, **“now returns all stat types by default”**. Its example includes K, DE, FS and OLB, not just offense. The June assertion that production files are necessarily offense-only is no longer a valid description of the replacement.

## Verification conventions
The web extension often returns no numeric HTTP status on success; “retrieved” below means content returned, not an invented HTTP 200. `application/octet-stream` rejection is the extension's decoder limitation, not an origin 403/404 and not proof of missing data. Release asset metadata proves a named file exists and its upload time; it does NOT prove the maximum season inside a multi-season file. No credentials sent. No dataset mirrors saved.

## Shared primary references
- **M1:** https://api.myfantasyleague.com/2026/api_info (retrieved developer terms). Free use with restrictions; no harvesting, no overloading, permission required for private user information. **“our player database is only changed once a day”**; cache league settings. No numeric request quota established.
- **M2:** https://api.myfantasyleague.com/2026/api_info?STATE=details (retrieved 2026 export reference). Documents the nine exports below. Documentation only, deliberately not a live league test.
- **N1:** https://nflreadr.nflverse.com/articles/nflverse_data_schedule.html (retrieved maintainer schedule). PBP/player stats nightly after game days plus game-day runs; Thursday refresh incorporates corrections. Snap counts, PFR advanced stats and FTN charting scheduled at 0/6/12/18 UTC, but actual availability depends on upstream. Roster/injury/depth-chart schedule daily 7AM UTC. Schedule is not a freshness guarantee.
